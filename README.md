# SIDE48簡易ビルドガイド
自作キーボードキットSIDE48の簡易板ビルドガイドです。<br>

## キット内容

| 名称                   | 数  |　補足                                  |
| ---------------------- | --- | ---                                   |
| キット本体              | 2   |マイコンなど実装済み                     |
| エンコーダノブ          | 2   |                                        |
| スイッチ取付面静音フォーム| 48   |                                       |
| 滑り止め                | 8    |                                       |
 
## キット以外に必要なもの

| 名称                     | 数  |　補足         |
| ----------------------   | --- | ---          |
| キースイッチ              | 48  |choc v2互換　　|
| キーキャップ              | 48  |choc v2互換　　|
| 19mmトラックボール        | 1   |           　　|
| 単4電池　　              | 2   |           　　|

## 組み立て手順
以下の状態で郵送されます。<br>
<img src="img/S__109133841_0.jpg" width="40%"><br>

この状態でキースイッチを刺してもよいですが、<br>
静音フォームを貼るとよい感じなのでケースを外します。<br>
裏返すと四隅にネジがあるので外します。<br>
ネジを外すとケース(トップ) が外せます。<br>
<img src="img/S__109133844_0.jpg" width="40%"><br>

静音用フォームを貼っていきます。<br>
<img src="img/S__109133851_0.jpg" width="40%"><br>
穴が塞がりますが、大丈夫です。<br>
後でスイッチを刺す際はこのまま挿して（フォームを貫通させて）問題ないです。<br>
<img src="img/S__109133851_0.jpg" width="40%"><br>

基板の四隅は3D製のダンパで打鍵感を良くしています。
フォームを貼っているときなどに外れたら図のようにはめなおしてください。
<img src="img/S__109133851_0.jpg" width="40%"><br>

次に、スイッチをはめていきます。<br>
上からスイッチースイッチプレートー基板となるようにはめます。<br>
クリックスイッチの足とスイッチプレートが干渉しないように、スイッチプレートには凹凸がありますので、
スイッチプレートは図の向きで使用してください。<br>
<img src="img/S__109133851_0.jpg" width="40%"><br>

スイッチを全て刺して、<br>
キーキャップを全てはめて、<br>
ロータリーエンコーダ用ノブを刺して、<br>
19mmトラックボールを置いて、<br>
ケースをはめてネジをしめたら、<br>
完成です！<br>
<img src="img/S__109133852_0.jpg" width="30%"><br>

## Bluetoothが繋がらない場合
PCとBluetoothのch選択が間違っている可能性があります。
Layer4にてBluetoothのchを変更してみてください。

それでもPCとBluetoothで接続できない場合は再度ファームウェアの書き込みを行ってください。<br>
右手用は下記の手順で実施します。<br>
・PCとSIDE48をUSBで接続します。<br>
・マイコン（XIAO BLE）のリセットボタンを2回連続で押すと、「XIAO SENSE」という名前でUSBドライブとして認識されます。<br>
・本レポジトリ内にある「SIDE48_RESET.uf2」を「XIAO SENSE」にドラック&ドロップします。<br>
　書込みが完了すると「XIAO SENSE」ドライブは消えます。<br>
・再度リセットボタンを2回連続で押して、本レポジトリ内の「SIDE48_R.uf2」にドラック&ドロップします。<br>

左手用は上記手順で最後に「SIDE48_L.uf2」を書きます。<br>
